## 修复的问题

在原型测试过程中发现并修复了以下问题：

1. **video_prompt 缺失**: storyboard 模板未生成 `video_prompt` 字段 → 新增后备 prompt 构造逻辑
2. **AI 输出不稳定**: 分镜脚本有时缺少 `shots` 数组 → 增加 `postWithRetry` 自动重试
3. **video_url 字段名**: Agnes 视频完成响应中 URL 在 `remixed_from_video_id` → 适配器增加回退提取
4. **Prisma 客户端过期**: schema 新增字段后需 `prisma generate`
5. **视频分辨率**: Agnes 输出 1280×768 → FFmpeg 后处理至 1080×1920

## 剩余风险

| # | 风险 | 缓解措施 |
|---|------|----------|
| 1 | 视频队列延迟不确定（10-30 min） | 异步模式 + task_id 持久化 + "继续检查"按钮 |
| 2 | 视频分辨率非原生 1080×1920 | FFmpeg scale+pad 后处理 |
| 3 | 批量生成 QPS 限制 | 串行创建 + 重试机制 |
| 4 | AI 输出偶有不稳定 | postWithRetry 自动重试 |
| 5 | API 返回字段可能变化 | Adapter 多字段回退兼容 |
