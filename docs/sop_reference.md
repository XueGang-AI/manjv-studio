【AI分析维度】
当你提供故事后，AI会进⾏7个维度的专业分析：

✓ 古⻛类：宫⽃、江湖、仙侠、穿越
✓ 现代情感：都市爱情、职场、家庭
✓ 悬疑类：推理、惊悚、反转剧情
✓ ⽞幻类：修仙、异能、系统流
✓ 甜宠类：校园、⻘梅⽵⻢、甜⽂

⽅案A：Seed固定法（最简单）

【如何打造爆款】
爆款公式：
⾼质量内容 × 情感共鸣 × 传播钩⼦ × 运⽓

- 观众代⼊感强
- 情感释放点精准
- 台词有⾦句
- ⼈设讨喜或讨厌但记忆深刻

- 话题性强（引发讨论）
- 争议性（正⾯或负⾯都可）
- 悬念强（必须看下⼀集）
- ⾦句多（可截图分享）
4. 运⽓（1%）
- 发布时间碰上流量⾼峰
- 正好契合当下热点
- 平台算法推荐
